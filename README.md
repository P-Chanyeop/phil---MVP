# 🐹 Phil — 이길 때까지 배우는 AI 트레이더 (한국 주식 모의투자)

> 같은 날을 반복하며 이길 때까지 배운 남자, 그리고 날씨를 예측하는 그라운드호그에서 따온 이름.

Phil 은 **코스피·코스닥 대형주**를 모의 자금 1,000만 원으로 **1~5일 스윙 매매**하고,
결과가 나오면 **스스로 회고하고 자기 전략을 고치는** AI 에이전트입니다.
오픈소스 [bennyjo/phil](https://github.com/bennyjo/phil) (Apache-2.0) 의 구조를 가져와 한국 주식용으로 다시 만들었습니다.

```
정산 → 회고("뭐가 틀렸지?") → 규칙 고치기 → 조사 → 예측 기록 → 매매 → (다음 날) 다시 도전
```

- **AI 판단**: 내 PC의 **Claude Code** 가 뉴스·공시·시세를 조사하고 확률을 정합니다.
- **시세**: 네이버 증권 공개 데이터 (키 필요 없음).
- **정직한 모의 체결**: 실시간 현재가 + 슬리피지 0.05%, 수수료 0.015%, 매도 시 증권거래세 0.20%(2026년 기준).
  청산은 일봉 기준(손절·목표·만기)이고, 같은 날 손절·목표가 둘 다 닿으면 손절로 봅니다.
- **정직한 지표**: 수익률을 **코스피와 비교**하고, "N일 뒤 오를까?" 확률이 그 종목의 **과거 기저율보다 정확한지**(brier Δ) 잽니다.

> 원래는 Polymarket(예측시장)용이었지만, 한국에서는 2026년 8월 방송통신심의위원회 결정으로 접속이 차단되어
> 한국 주식 모의투자로 바꿨습니다.

## 2. 실행

1. 코드 받기: [ZIP 다운로드](https://github.com/P-Chanyeop/phil---MVP/archive/refs/heads/claude/friendly-goldberg-sqe2wj.zip) 후 압축 풀기
   (또는 `git clone -b claude/friendly-goldberg-sqe2wj https://github.com/P-Chanyeop/phil---MVP.git`)
2. **Windows**: `start.bat` 더블클릭 / **Mac·Linux**: `./start.sh`
3. 브라우저에서 **http://127.0.0.1:8787** 이 열립니다. 까만 창은 닫지 말고 최소화해 두세요.

### 언제 무엇을 하나
| 시간 | 버튼을 누르면 | 비용 |
|---|---|---|
| **평일 09:05~15:15 (장중)** | 회고 → 조사 → 예측 기록 → 매수·매도 | 회당 약 $0.2~1 |
| 장 마감 후·주말 | 정산 후, 새로 끝난 매매가 있으면 회고·전략 수정만 | 없으면 $0 |
| 시세 접속 실패 | Claude 를 부르지 않음 | $0 |

**자동 반복**을 켜면 장중에는 설정한 간격(기본 2시간)마다, 평일 15:45 에 한 번 더(정산·회고) 실행합니다.
PC 와 Phil 창이 켜져 있어야 합니다 (계속 켜 두려면 아래 "서버에 올리기").

**실시간 감시**: Phil 이 켜져 있으면 장중 1분마다 보유 종목의 손절가·목표가를 확인해 바로 청산하고,
만기일에는 15:15 에 청산합니다. Claude 를 부르지 않아서 비용이 없습니다.

로그인이 만료되면 화면에 안내가 뜹니다 (터미널에서 `claude` → `/login`).

## 3. 규칙

**엔진이 강제 (에이전트가 못 바꿈, `config/protected.json`)**
- 확률은 항상 "N거래일 뒤 종가 > 지금 가격?" 에 대한 것. **내 확률 − 기저율 ≥ 0.05** 일 때만 매수.
  기저율 = 그 종목 최근 250거래일 중 N일 뒤 올랐던 비율.
- 종목당 자산의 10%, 동시 15종목, 사이클당 신규 5종목, 보유 1~5거래일, **손절 2~10% 필수**.
- 유니버스: 코스피 시총 상위 200 + 코스닥 상위 100 (우선주·스팩 제외). 장중에만 매매·예측.
- 조사한 후보는 돈을 안 걸어도 **예측으로 기록** → 근거 유형(실적·공시·뉴스·모멘텀 등)별로 정확도를 재고,
  30건 이상 쌓였는데 기저율보다 못한 근거 유형은 **자동으로 매수 금지**.

**에이전트가 스스로 고치는 것 (`strategy/`)**
- `playbook.md`: 셋업(가설), 확률 정하는 법, 피할 것, 배운 것
- `risk.json`: 포지션 크기, 손절 기본값 등

**안전장치**
- 에이전트는 `python tools.py` 외의 명령을 실행할 수 없고, 엔진·설정·원장 파일을 고치면 사이클 후 자동 복구됩니다.
- 에이전트는 Phil 폴더 안의 파일만 읽을 수 있고, `.env` 와 한투 토큰은 읽을 수 없습니다.

## 4. 한투 모의투자 계좌 연동 (선택)

Phil 의 모의 매매를 **한국투자증권 모의투자 계좌**에도 똑같이 시장가 주문합니다 (실제 돈 아님).
실제 증권사 체결을 거치므로, 나중에 실계좌로 넘어가기 전 연습이 됩니다.

1. [KIS Developers](https://apiportal.koreainvestment.com) 에서 모의투자 신청 → 앱키·시크릿 발급
2. `.env` 에 `PHIL_KIS_APP_KEY`, `PHIL_KIS_APP_SECRET`, `PHIL_KIS_ACCOUNT`(모의계좌 10자리) 입력 → Phil 재시작
3. 설정 탭 → **연동 켜기**. 켠 뒤 새로 산 종목부터 따라 사고, 장부에서 청산되면 따라 팝니다.

- 주소가 모의투자 서버로 고정되어 있어 **실계좌 주문은 불가능**합니다.
- 키는 엔진만 쓰고 AI 에는 전달되지 않습니다.
- 한투 API 는 이 저장소에서 실제 계좌로 시험하지 못했습니다 (거래 ID 는 한투 공식 예제 기준).
  처음 켜고 첫 주문이 나가면 설정 탭의 주문 기록과 한투 앱의 모의계좌를 함께 확인해 주세요.

## 5. 서버(AWS)에 올리기

PC 를 계속 켜 둘 수 없으면 서버에 올리세요. 다른 서비스가 있는 서버에도 전용 사용자로 격리해서 설치됩니다.
**[deploy/SERVER.md](deploy/SERVER.md)** 를 따라 하면 됩니다 (`sudo bash deploy/install.sh` 한 줄 + 로그인).

## 6. 기대치 (솔직하게)

대형주의 며칠짜리 움직임은 대부분 잡음이고, 왕복 비용이 약 0.33% 입니다.
AI 가 이걸 꾸준히 이길 수 있는지는 **아직 아무도 모릅니다** — 그걸 확인하는 실험입니다.
2~4주 이상 돌려서 저널 탭의 "기저율보다 정확", "검증된 엣지" 표시가 생기는지 보세요.
실계좌 주문은 모의 성적이 쌓인 뒤 따로 붙일 예정입니다.

journal/         원장·예측·회고·로그 (로컬 데이터, git 제외)
